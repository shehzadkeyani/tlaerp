# TLA ERP

Construction ERP prototype with spreadsheet-style data entry and a backend-ready persistence layer.

## Run locally

```bash
npm start
```

Then open http://localhost:8000

## Included

- spreadsheet-style ERP shell for setup, transactions, documents and reporting
- controlled dropdown-based entry for master data
- JSON-backed server persistence for sheet state, ledgers, budgets and documents
- seed data for construction projects and reporting examples
